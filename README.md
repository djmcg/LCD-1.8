Sterownik SPI i panel webowy dla ekranu ST7735S 128x160 px.

## Funkcje
- Sprzetowy sterownik SPI ST7735S z kontrola podswietlenia i obrotu (0-270 stopni).
- Proceduralny wygaszacz CMatrix (~25 FPS).
- Web UI z podgladem na zywo (Live Preview), obsluga GIF-ow i pogody.
- Wielojezycznosc (PL / EN).
- Autostart jako usluga systemd.
